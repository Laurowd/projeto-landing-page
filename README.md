# Projeto Landing Page

Landing page desenvolvida no modulo base do curso de Tecnologia da Escola DNC.

O objetivo do projeto foi praticar estrutura HTML, estilização com CSS e interacoes simples com JavaScript em uma pagina de apresentacao.

## Tecnologias

- HTML
- CSS
- JavaScript

## Funcionalidades

- Pagina inicial com conteudo institucional
- Secoes com informacoes do produto/servico
- Componentes visuais organizados em cards
- Interacoes simples com JavaScript

## Como executar

Clone o repositorio e abra o arquivo `index.html` no navegador.

```bash
git clone https://github.com/Laurowd/projeto-landing-page.git
cd projeto-landing-page
```
